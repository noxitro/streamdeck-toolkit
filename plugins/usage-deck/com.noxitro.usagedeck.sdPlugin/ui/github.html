__MSG_howTo__

Shared by all GitHub keys. Leave blank to use gh auth token (run gh auth login once). A fine-grained token needs the Plan: read user permission.

Work accounts: if your Copilot license is managed and billed by an organization or enterprise, that usage is not in your personal billing data, so the key shows little or nothing. An organization administrator can enter the organization name to see the organization's usage instead (other members get "No access").

Shows this month's usage (UTC). With a budget, the bar shows usage against it and the marker shows how far through the month you are. Without one, the amount in dollars is shown.

Press to refresh, hold to open GitHub billing usage.

すべての GitHub キーで共通の設定です。空欄なら gh auth token を使います(事前に gh auth login が必要)。Fine-grained トークンを使う場合は、ユーザー権限の Plan: read が必要です。

職場のアカウント: Copilot のライセンスが組織や Enterprise で管理・課金されている場合、その利用量は個人の請求データに含まれないため、キーにはほとんど(または何も)表示されません。組織の管理者は「組織名」を入れると、組織全体の利用量を表示できます(管理者以外は「権限なし」になります)。

今月(UTC)の利用量を表示します。上限を入れるとバーで消費率を表示し、目盛りは月の経過を示します。未入力のときはドル金額を表示します。

押すと更新、長押しで GitHub の請求ページを開きます。
