Shared by all Claude keys.

Claude Code CLI: the plugin asks the installed claude CLI for your usage, the same numbers as /usage. It never reads or stores a token; the CLI keeps its own login fresh. Sign in once with claude → /login. The key shows "Run /login" when the CLI is signed out, and "Unavailable" when it is signed in but couldn't get usage right now (offline, rate limited).

claude path: leave empty; it's found on PATH, in ~\.local\bin and in npm's global folder. Only if the key shows "No claude CLI", enter the full path of claude.exe (or the folder, or npm's claude.cmd, which is mapped to the real exe). For npm installs it is <npm prefix -g>\node_modules\@anthropic-ai\claude-code\bin\claude.exe. %VARS% and ~ are expanded; network paths are not accepted.

Press to refresh (at most once a minute), hold to open claude.ai usage. A yellow dot means the last refresh failed and older data is shown.

すべての Claude キーで共通の設定です。

Claude Code CLI: インストール済みの claude CLI に使用量を問い合わせます(/usage と同じ値)。プラグインはトークンを読まず、保存もしません。ログインの更新は CLI が自分で行います。最初に一度だけ claude → /login でログインしてください。CLI がログアウト状態のときはキーに「要ログイン」、ログイン済みでも今は取得できない(オフライン・レート制限など)ときは「取得不可」と表示されます。

claude のパス: 通常は空欄のままで構いません(PATH、~\.local\bin、npm のグローバルフォルダから自動で探します)。キーに「CLI未検出」と出るときだけ、claude.exe のフルパスを入れてください(フォルダや npm の claude.cmd を指定しても実体の exe に読み替えます)。npm で入れた場合の場所は <npm prefix -g の出力>\node_modules\@anthropic-ai\claude-code\bin\claude.exe です。%変数% と ~ は展開されます。ネットワーク上のパスは使えません。

押すと更新(最短1分間隔)、長押しで claude.ai の利用状況ページを開きます。右上の黄色い点は、最後の更新に失敗して古いデータを表示していることを示します。
